# mappings

Реестр адресов Sacred Gold для тех, кто добавляет хуки в загрузчик или
изучает код игры.

Каждая запись называет функцию, глобальную переменную или поле структуры,
указывает адрес и соглашение о вызове и говорит, насколько запись надёжна. В
заметках хранятся доказательства, ограничения и все неудачные места для хуков.
Так никому не придётся дважды ронять игру по одной и той же причине.

Все адреса относятся к одной сборке: 32-битному `pureHD.exe` версии 2.0.2.118
с image base `0x00400000`. Это оболочка от сообщества, которая поставляется с
`pHD.dll`. Штатный `Sacred.exe` — другой бинарный файл, и для него, как и для
любой другой сборки, эти адреса неверны.

Адреса я нашёл с помощью Frida, Cheat Engine и Ghidra на своей офлайн-копии
игры. Загрузчик не меняет файлы игры на диске. Хуки живут только в памяти и
исчезают вместе с процессом.

| Файл | Что это |
|---|---|
| `mappings.txt` | Реестр и единственный файл, который правят вручную |
| `mappings.json` | Генерируется из реестра, его читают другие репозитории |
| `mappings.generator.py` | Собирает и проверяет `mappings.json` |

## Как начать

Чтобы добавить запись:

1. Откройте `mappings.txt` и найдите нужный раздел.
2. Добавьте строку. Колонки выровнены для людей, а генератор читает только
   первые два поля, разделённые пробелами.
3. Запустите `python mappings.generator.py`.
4. Закоммитьте `mappings.txt` и `mappings.json` вместе.

У каждого раздела своя строка заголовка:

```
# VA          RVA        NAME                              CONV/ARGS -> RET                        CONF       NOTES

0x00604380  0x204380   cObjectManager::getLocalHero      thiscall() -> cCreatureHero*             confirmed  [key=getLocalHero hooked] NULL on the main menu. The hero-capture point for every hook.
```

В строках кода указаны оба адреса, и RVA равен VA минус `0x00400000`. Frida
работает с RVA, Ghidra и Cheat Engine — с VA. Если их перепутать, ошибки не
будет. Хук просто не сработает.

У глобальных переменных указан только VA. Строки в `STRUCTURES` начинаются с
`+0x` и описывают смещения, а не адреса.

`CONF` принимает ровно три значения:

- `confirmed` — поведение видели в запущенной игре.
- `static` — вывод сделан по дизассемблеру, в игре ещё не проверен.
- `suspect` — правдоподобно, но не проверено или противоречит другим данным.

Ошибочная запись обходится дороже отсутствующей. Не оставляйте `confirmed` без
проверки в игре. Если подтверждение перестало держаться, понизьте запись до
`suspect` и объясните причину в заметках.

Некоторые строки нужны только для предупреждения об опасном месте:

```
0x00562D10  0x162D10   regen write                        mov [ebp+0x130], edi                     confirmed  DO NOT HOOK: per creature per tick (~10/s for the player alone).
```

Записи не удаляют. Ошибочную исправляют или помечают `suspect`, а причину
оставляют в заметках. `mappings.json` тоже не правят вручную: следующий запуск
генератора его перезапишет.

### Когда запись нужна коду по имени

Поставьте тег экспорта в самое начало колонки заметок:

- `[key=addExperience]` экспортирует адрес как `rva.addExperience`, а для
  глобальной переменной с одним адресом — как `va.addExperience`.
- `[key=hpDamage hooked]` вдобавок заносит имя в `hooked`. Агент ставит там
  перехватчик, поэтому это место обязан проверить `hooksafe.py`.

Запись без тега остаётся документацией и в `mappings.json` не попадает. Ключи
уникальны во всём файле. Если две записи описывают один адрес, ключ может
быть только у одной из них.

## Формат mappings.json

В файле три рабочих раздела и служебные поля `_` и `_hooked` с пояснениями:

```json
{
  "rva": { "getLocalHero": "0x204380", "hpDamage": "0x16FC44" },
  "va": { "xorMirror1": "0x182DDDC" },
  "hooked": ["getLocalHero", "hpDamage"]
}
```

Строки с двумя адресами попадают в `rva`, глобальные переменные с одним
адресом — в `va`. В `hooked` перечислены места перехватчиков. Генератор
сверяет RVA из строки, а экспортируемое значение вычисляет из VA.

## Кто читает реестр

`coderpack/tools/paths.py` ищет `mappings.json` в таком порядке: путь из
командной строки, `$CODERPACK_MAPPINGS`, соседний `../mappings`, кэш
`build/mappings/mappings.json` и, наконец, загрузка с GitHub. Для загрузки
берётся ревизия из `coderpack/.mappings-ref`, а если файла нет или он пуст —
`master`.

`coderpack/tools/addr.py` превращает `rva` и `va` в
`coderpack/agent/src/gen/addr.js`. Адрес, вписанный в код агента вручную, —
ошибка.

`coderpack/tools/hooksafe.py` дизассемблирует игру в каждой точке из `hooked`
и ищет опасности для трамплина. Фатальны переход внутрь заменяемых байтов,
инструкция, выставляющая флаги, оторванная от своего перехода, и пересечение
хуков. Кроме того, инструмент предупреждает о переносе управляющих
инструкций, обращениях через ESP и временных регистрах, которые должны
пережить патч.

Запись навыка по `+0x1827DA` показывает, зачем нужна проверка переходов. Её
инструкция занимает четыре байта, следующая оказывается внутри патча, и на неё
указывают два перехода. Хук здесь ронял игру при загрузке персонажа с пустым
слотом навыка. Вручную причину искали три перезапуска игры. Безопасная точка —
`+0x1827DE`.

`launcher/tools/build.ps1` пересоздаёт `addr.js`, когда собирает coderpack из
исходников. Путь `$Mappings` он передаёт, только если там лежит
`mappings.json`. Иначе coderpack ищет реестр в обычном порядке.

## Сборка

Генератору нужен Python 3.11 или новее и ничего сверх стандартной библиотеки:

```
python mappings.generator.py            # пишет mappings.json
python mappings.generator.py --check    # выходит с кодом 1, если файл устарел
```

`--check` собирает JSON в памяти, сравнивает с файлом в репозитории и ничего
не пишет. При совпадении печатает `mappings.json is up to date.` и выходит с
кодом 0. Иначе печатает команду для пересборки и выходит с кодом 1. Ту же
проверку CI запускает на каждый push и pull request.

В обоих режимах генератор проверяет реестр и отвергает:

- неверный VA или неверное второе поле, если оно начинается с `0x`
- RVA, не равный `VA - 0x00400000`
- `[key=...]` в строке без адреса
- неверное содержимое тега
- повторный ключ, с номером строки, где он встретился впервые
- отдельный `[hooked]`
- `hooked` у глобальной переменной с одним адресом
- реестр без единой экспортируемой RVA

В ошибках конкретной строки указан её номер.

Разбор начинается с первой строки, которая начинается с `##`. Заголовок выше
содержит примеры тегов и пропускается намеренно, как и любая адресная строка
над ним. В строке с двумя адресами RVA должен стоять во втором поле. Иначе
генератор примет её за глобальную переменную и экспортирует VA в `va`.

## Релизы

У реестра нет релизов. Потребители читают `mappings.json` из `master` или с
ревизии, закреплённой в `coderpack/.mappings-ref`. До игроков изменение
доходит со следующим релизом coderpack, как описано в корневом
[CONTRIBUTING](https://github.com/ancaria-dev/.github/blob/master/CONTRIBUTING.md).
