# mappings

Здесь собраны известные адреса функций Sacred Gold, соглашения о вызовах,
смещения полей в структурах и уровень достоверности каждой записи.

Все данные относятся к 32-битному `pureHD.exe` версии 2.0.2.118 с image base
`0x00400000`. Это сторонняя оболочка, которая поставляется с `pHD.dll`.
Штатный `Sacred.exe` представляет собой другой бинарный файл. Для любой другой
сборки адреса будут неверны. Реестр вынесен отдельно от использующего его кода,
поэтому код можно менять, не теряя результаты анализа бинарного файла.

| Файл | Что это |
|---|---|
| `mappings.txt` | Реестр и единственный файл, который правят вручную |
| `mappings.json` | Сгенерированный файл, который читают другие репозитории |
| `mappings.generator.py` | Генератор и валидатор JSON |

## Как добавить запись

Откройте `mappings.txt`, найдите нужный раздел и добавьте запись. Колонки
выровнены для чтения, а генератор разбирает первые поля по пробельным
разделителям. У каждого раздела свой заголовок:

```
# VA          RVA        NAME                              CONV/ARGS -> RET                        CONF       NOTES

0x00604380  0x204380   cObjectManager::getLocalHero      thiscall() -> cCreatureHero*             confirmed  [key=getLocalHero hooked] NULL on the main menu. The hero-capture point for every hook.
```

В тегированных строках, которые должны попасть в `rva`, указывают VA и RVA. RVA
равен VA минус `0x00400000`. Frida использует RVA, а Ghidra и Cheat Engine
используют VA. Если их перепутать, хук может молча не сработать. У глобалов
указан только VA, а строки в `STRUCTURES` начинаются с `+0x` и описывают
смещения, а не адреса.

Колонка `CONF` принимает только три значения:

- `confirmed` означает, что поведение наблюдали в запущенной игре
- `static` означает, что запись получена из дизассемблера и ещё не проверена во
  время выполнения
- `suspect` означает, что запись выглядит правдоподобно, но не проверена, либо
  противоречит другим данным

Ошибочная запись обходится дороже отсутствующей. Если подтверждения нет,
понизьте уровень уверенности вместо того, чтобы оставлять `confirmed`.

В заметках хранится обоснование записи. Некоторые строки нужны прежде всего для
предупреждения о небезопасном месте:

```
0x00562D10  0x162D10   regen write                        mov [ebp+0x130], edi                     confirmed  DO NOT HOOK: per creature per tick (~10/s for the player alone).
```

Строки не удаляют. Ошибочную строку исправляют, а причину указывают в заметках.

### Когда запись нужна коду по имени

Добавьте тег в самое начало колонки заметок:

- `[key=addExperience]` экспортирует адрес как `rva.addExperience`, либо как
  `va.addExperience`, если это глобал с единственным адресом
- `[key=hpDamage hooked]` экспортирует адрес и добавляет имя в `hooked`, потому
  что агент устанавливает в этой точке перехватчик. Такие точки проверяет
  `hooksafe.py`

Запись без тега остаётся документацией и в JSON не попадает. Имена ключей
уникальны во всём файле. Две записи одного адреса могут содержать не более
одного ключа между собой.

После изменения пересоберите JSON:

```
python mappings.generator.py
```

Коммит должен включать `mappings.txt` и обновлённый `mappings.json`.
`mappings.json` нельзя править вручную, поскольку следующий запуск генератора
его перезапишет.

## Генератор

Генератор использует только стандартную библиотеку и требует Python 3.11 или
новее.

```
python mappings.generator.py            пишет mappings.json
python mappings.generator.py --check    падает, если mappings.json устарел
```

`--check` собирает JSON в памяти и сравнивает с файлом на диске. Он ничего не
пишет. При совпадении он печатает `mappings.json is up to date.` и завершает
работу с кодом 0. При расхождении печатает команду для пересборки в stderr и
выходит с кодом 1. В этом репозитории нет CI, поэтому проверку запускают
вручную перед коммитом.

В обоих режимах генератор проверяет:

- формат первого адреса и RVA, если второе поле начинается с `0x`
- равенство RVA выражению `VA - 0x00400000`
- наличие тега только в адресной строке
- формат `[key=<name>]` и `[key=<name> hooked]`
- уникальность ключей во всём файле
- отсутствие отдельного `[hooked]`
- отсутствие `hooked` у глобала, где нет кода для перехвата
- наличие хотя бы одной тегированной строки с парой VA и RVA

Ошибки конкретных строк содержат номер строки. Если генератор не находит ни
одной экспортируемой RVA, он сообщает, что `mappings.txt` может быть повреждён.
Текст до первой строки, начинающейся с `##`, не разбирается. Поэтому адресную
запись нельзя добавлять выше первого заголовка раздела.

JSON содержит три рабочих раздела, `rva`, `va` и `hooked`, а также служебные
поля `_` и `_hooked` с пояснениями. Схема рабочих данных выглядит так:

```json
{
  "rva": { "getLocalHero": "0x204380", "hpDamage": "0x16FC44" },
  "va": { "xorMirror1": "0x182DDDC" },
  "hooked": ["getLocalHero", "hpDamage"]
}
```

Тегированные строки с двумя адресами попадают в `rva`, тегированные глобалы с
одним адресом попадают в `va`, а `hooked` содержит имена точек, к которым
подключается агент. Экспортируемый RVA генератор вычисляет из VA после проверки
RVA, записанного в строке.

## Кто это читает

Путь к `mappings.json` определяет `coderpack/tools/paths.py`. Сначала он
проверяет путь из командной строки, затем `$CODERPACK_MAPPINGS`, соседний
`../mappings` и кэш `build/mappings/mappings.json`. Если файла нет, инструмент
скачивает его из репозитория mappings на GitHub. Для скачивания используется
ревизия из `coderpack/.mappings-ref` или `master`, если файл отсутствует или
пуст.

`tools/addr.py` создаёт `agent/src/gen/addr.js` из `rva` и `va`. Адрес, введённый
в коде агента вручную, считается ошибкой.

`tools/hooksafe.py` читает все имена из `hooked`, дизассемблирует бинарный файл
игры и сообщает об опасных местах для трамплина. Фатальными считаются переход
внутрь заменяемых байтов, отделение инструкции, выставляющей флаги, от
использующего их перехода и пересечение двух перехватчиков. Отдельные
предупреждения относятся к переносу управляющих инструкций, обращениям через
ESP и временным регистрам, значение которых должно пережить патч.

Эту проверку добавили после сбоя на записи навыка по `+0x1827DA`. Инструкция
занимает четыре байта, а два `jmp` указывают точно на следующую инструкцию. Из-за
этого игра падала при загрузке персонажа с пустым слотом навыка. Причину нашли
вручную после трёх перезапусков игры. Безопасная точка находится по
`+0x1827DE`.

`launcher/tools/build.ps1` пересоздаёт `agent/src/gen/addr.js` при сборке
Coderpack из исходников и подготовке payload. Если по пути `$Mappings` есть
`mappings.json`, скрипт передаёт этот путь в `python tools/addr.py`. В противном
случае он запускает команду без пути, после чего Coderpack использует обычную
цепочку поиска.

Адреса найдены через Frida, Cheat Engine и Ghidra на локальной офлайн-копии игры.
Файлы игры на диске не изменяются. Перехватчики работают только в памяти
процесса и исчезают после его завершения.
